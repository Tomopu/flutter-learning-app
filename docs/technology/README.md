# technology

このディレクトリでは、実装に入る前に揃えておく技術方針を管理します。

MVPでは、第一段階としてローカルDocker上でアプリケーション全体を動かし、第二段階としてクラウド上のサーバービルド方式へ拡張することを前提にします。

## 技術方針の要点

- APIは学習者向け、管理者向け、ビルド実行、LLM連携の責務を分ける
- DBは教材、ロードマップ、教材ステップ、ビルド履歴、LLM生成履歴を扱える構成にする
- MVP第一段階ではローカルDocker前提で簡潔に実装し、第二段階で認証、認可、キュー、監視、クラウドストレージへ拡張する
- サーバービルドでは、ビルド用ワークスペースとアプリケーション本体を分離する
- Admin機能はMVPから扱うが、外部公開時には必ず認証・認可を導入する
