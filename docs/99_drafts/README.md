# drafts

このディレクトリでは、下書き、未整理メモ、試作物、旧画像を管理します。

下書きは長くても構いません。ただし、実装判断の根拠として使う内容は、必ず正式文書へ整理してから反映します。

## 構成

- [01_requirements/](01_requirements/): 要求仕様に関する下書き
- [02_design/](02_design/): 設計に関する下書き
- [03_research/](03_research/): 調査メモ、比較検討、外部情報の整理
- [04_prototypes/](04_prototypes/): 画面や機能のプロトタイプ
- [05_images/](05_images/): 下書き画像、旧画像、比較用画像

## 管理方針

- 下書きは読みやすさよりも情報を失わないことを優先する。
- 正式文書へ反映した内容は、必要に応じて反映済みであることを残す。
- AIに読ませる情報は、下書き全文ではなく正式文書または短い要約を優先する。
