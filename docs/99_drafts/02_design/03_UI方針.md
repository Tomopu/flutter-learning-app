# UI方針

## コンセプト

開発ツール・IDEに近い操作感を持つ、ダークモード中心のUIを基本とする。
学習者がコードとドキュメントに集中できるよう、装飾は最小限にする。
コンテンツエリアはカード形式で浮かせたデザインとし、Zenn風の読みやすさを意識する。

### ライトテーマ

`data-theme="light"` 属性をルートに付与することで切り替え可能。プロトタイプで実装済み。
ページ背景は `#eef1f6`、カードは `#ffffff` ベース。バッジ・ステータス色はライトモード向けに調整済み。
エディタ領域（`.dark-zone`）は常にダーク配色を維持し、テーマに依存しない。

## タイポグラフィ

| 用途 | フォント | 変数名 |
|------|--------|--------|
| UI全般・教材本文 | Noto Sans JP → system font フォールバック | `--font-ui` |
| コードエディタ・ファイルパス・バッジ等 | JetBrains Mono → Fira Code → monospace フォールバック | `--font-mono` |

## レイアウト原則

- 左右ペイン（S02）はドラッグでリサイズ可能。初期値は左 360px（min 240px / max 720px）
- 下部パネル（S02）はドラッグでリサイズ可能。初期値は 320px（min 120px / max 720px）
- S01・S02・S03のコンテンツエリアはカード形式（角丸・ドロップシャドウ）で背景から浮かせる
- レスポンシブ対応は初期スコープ外（デスクトップ幅前提）

## コンポーネント方針

| コンポーネント | 選定 | 備考 |
|--------------|------|------|
| コードエディタ | Monaco Editor | VSCodeと同エンジン。`flearn-dark` カスタムテーマを定義 |
| Markdownレンダリング | react-markdown 等の標準ライブラリ | 教材本文・解答・Adminプレビューで使用 |
| ファイルツリー | 独自実装 | 折りたたみ可能なツリー。DnD不要 |
| コンソール表示 | 独自実装（`<pre>` スクロール） | タイムスタンプ＋色分け（info/ok/err/warn） |
| LLMチャット | 独自実装 | バブル形式、スクロール、送信ボタン |
| ダイアログ | 独自実装 | 確認・警告・破壊的操作ごとにスタイルを変える |

## 学習画面のタブ方針

S02 学習メイン画面の左ペインには `教材`、`解答`、`LLM` の順でタブを配置する。

解答タブは学習者が自力で考えた後に確認するための補助として扱う。初回表示時はゲート画面を挟み、明示的な操作なしには解答が表示されないようにする。ゲートを通過後は「コピー」「エディタに反映」が使用可能になる。「エディタに反映」は `lib/main.dart` を上書きする破壊的操作だが、確認ダイアログは設けずボタンラベルで意図を明示する。

ビルドとリセットはトップツールバーに配置する。ビルドステータス（成功・失敗・経過秒数）もツールバー内に表示する。ダウンロード・アップロード機能はMVPスコープ外とする。

## UIの優先順位

1. 機能が正しく動くこと（壊れていないこと）
2. 操作が直感的であること
3. 視覚的な洗練度

MVPでは3よりも1・2を優先する。デザインの統一やアニメーションは後回しでよい。
