# ユースケース

このドキュメントでは、学習者と管理者がプロダクトを利用する主要なシナリオを整理します。

## 1. 目的

要求仕様を画面設計、API設計、受け入れ基準へ落とし込むために、ユーザー視点の操作単位を明確にします。

## 2. ユーザー種別

- 学習者: 教材を選択し、コードを編集し、ビルド結果や解説を確認しながら学習するユーザー。
- 管理者: 教材、ロードマップ、公開状態、LLM生成内容を管理するユーザー。

## 3. 学習者ユースケース

### 3.1 教材を探して学習を開始する

- 学習者は教材一覧から学習したい教材を選択する。
- システムは教材概要、難易度、言語ラベル、公開状態に基づいて教材を表示する。
- 学習者は教材詳細を開き、学習メイン画面へ遷移する。

### 3.2 コードを編集して実行結果を確認する

- 学習者は教材本文を読みながらコードを編集する。
- 学習者はビルドを実行する。
- システムはビルドログ、エラー、プレビューを表示する。

### 3.3 模範解答を確認する

- 学習者は必要に応じて模範解答の表示を要求する。
- システムは確認を挟んだうえで、Markdown形式の模範解答を表示する。
- システムは学習者の現在のコードを上書きしない。

### 3.4 LLMに質問する

- 学習者は教材内容や現在のコードについて質問する。
- システムは必要なコンテキストを付与してLLMへ問い合わせる。
- システムは回答を学習画面内に表示する。

## 4. 管理者ユースケース

### 4.1 教材を作成・編集する

- 管理者は教材本文、初期コード、模範解答、メタ情報を編集する。
- システムは編集内容を保存し、公開状態を管理できるようにする。

### 4.2 LLMで教材下書きを生成する

- 管理者は到達目標や成果物を入力する。
- システムはロードマップ案と教材下書きを生成する。
- 管理者は生成内容を確認し、必要に応じて修正してから公開する。

### 4.3 教材を一括管理する

- 管理者は教材一覧から複数教材を選択する。
- システムは公開状態変更、一括削除、言語ラベル管理を提供する。
