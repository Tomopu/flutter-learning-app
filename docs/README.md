# docs

このディレクトリでは、新規開発に必要な要求仕様、組織内標準、設計書、開発管理、参考情報、画像、下書きを管理します。

ドキュメントは、正式文書と下書きを分けて管理します。正式文書は実装判断の根拠として扱い、下書きは未整理の検討内容、長い思考ログ、試作物、参考メモを置く場所として扱います。

## 構成

- [01_requirements/](01_requirements/): 何を作るか、何を満たすべきかを定義する要求仕様
- [02_standards/](02_standards/): 開発・設計・文書化における規約や方針
- [03_design/](03_design/): 要求仕様をどう実現するかを定義する設計書
- [04_project/](04_project/): 開発計画、進め方、マイルストーン管理
- [05_references/](05_references/): 外部リンク、参考記事、調査の根拠
- [99_drafts/](99_drafts/): 下書き、未整理メモ、試作物、旧画像

## 管理方針

- 正式文書は `01_requirements/`、`02_standards/`、`03_design/` を中心に管理する。
- 長文の検討ログや未整理メモは [99_drafts/](99_drafts/) に置く。
- 実装時に参照する判断は、下書きではなく正式文書へ反映してから使う。
- AIに読ませる前提の短い要約が必要になった場合は、正式文書の先頭に `AI Summary` を追加するか、別途 `ai-context/` を作成する。
