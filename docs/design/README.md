## 設計方針の要点

- S01は教材一覧画面とし、学習開始の起点にする
- S02は学習メイン画面とし、教材、コードエディタ、プレビュー、コンソール、ファイルツリー、LLM、模範解答を統合する
- S02の左ペインには、`教材`、`LLM`、`模範解答` のタブを置く
- S02の操作バーには、ビルド、ダウンロード、アップロード、リセットを置く
- 模範解答はMarkdown形式で表示し、現在のコードは上書きしない
- S03はAdmin画面とし、教材追加、編集、公開状態管理、LLM教材生成を扱う
- レスポンシブ対応はMVPでは必須とせず、デスクトップ幅を前提にする

## プロトタイプ管理方針

画面プロトタイプは `prototypes/` 配下にプロトタイプ単位のディレクトリを作って管理します。

プロトタイプに含める主なファイルは、HTML、JSX、CSS、データ定義、確認用スクリーンショットです。

生成物やOS固有ファイルは、必要がなければコミット対象に含めません。
