# 画面一覧

## 画面構成

| ID | 画面名 | 役割 | MVP対象 |
|----|--------|------|---------|
| S01 | 教材一覧画面 | コース・レッスン一覧を表示し、学習を開始する起点 | ○ |
| S02 | 学習メイン画面 | 教材閲覧・コード編集・実行・LLM質問を行う中心画面 | ○ |
| S03 | Admin画面 | 教材の追加・編集・プレビュー確認・承認・公開管理 | ○ |

## 画面遷移

```text
S01 教材一覧
 └─ レッスン選択
     └─ S02 学習メイン画面

S03 Admin画面（独立）
 └─ 教材一覧（draft/published）
     ├─ 教材編集ビュー
     │   ├─ メタデータ入力
     │   ├─ 本文・初期コード・模範解答編集（タブ切替）
     │   └─ プレビュー確認 → 承認して公開
     └─ 教材承認・公開操作（一覧から直接 / 一括）
```

## 各画面の概要

### S01 教材一覧画面

学習を始めるトップページ。利用可能なコース・レッスンをカード形式で表示する。

- コース一覧（将来的にはFlutter以外も）
- 各レッスルのタイトル、説明、難易度、進捗状態
- レッスン選択でS02へ遷移

### S02 学習メイン画面

本プロダクトのコア画面。以下の機能パネルを1画面に統合する。

- **教材パネル（左ペイン・タブ①）**: Markdown形式の教材本文を表示
- **LLMチャットパネル（左ペイン・タブ②）**: 教材・コード・エラーをコンテキストにしたAI質問
- **ファイルツリー（右ペイン・上部）**: 編集対象ファイルの一覧（VSCode風）
- **コードエディタ（右ペイン・中央）**: Dart/Flutterコードの編集
- **プレビュー / コンソール（右ペイン・下部・タブ切替）**: ビルド結果のプレビューとビルドログ表示

### S03 Admin画面

教材のライフサイクル全体を管理する管理者向け画面。学習者向けの画面とは独立して存在する。

- draft / published 状態の教材一覧を表示（フィルタ・ソート対応）
- 教材の新規追加・編集（教材本文・初期コード・模範解答をタブ切替）
- **プレビュー確認**: 編集中コンテンツをレンダリング表示で確認してから承認
- 承認操作（draft → published）：個別ボタン / 一括操作の両方に対応
- 公開済み教材の確認・非公開化
