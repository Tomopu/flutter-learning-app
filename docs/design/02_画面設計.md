# 画面設計

## S01 教材一覧画面

### レイアウト

```text
┌─────────────────────────────────────────────────────────────┐
│  [ロゴ / プロダクト名]                                        │  ← ヘッダー
├─────────────────────────────────────────────────────────────┤
│  言語: [すべて] [Flutter] [JavaScript] [Python] ...         │  ← 言語フィルタ
├──────┬──────────────────────────┬────────────┬──────┬──────┤
│  #   │ タイトル                  │ 言語       │ 難易度│ 概要│
├──────┼──────────────────────────┼────────────┼──────┼──────┤
│  001 │ Hello World               │ Flutter    │ 入門  │ 最初…│
│  002 │ Widget基礎                │ Flutter    │ 入門  │ Wid…│
│  003 │ 状態管理                  │ Flutter    │ 中級  │ Sta…│
└──────┴──────────────────────────┴────────────┴──────┴──────┘
```

- 言語フィルタはDBに登録済みの言語ラベルを動的に列挙
- 言語列ヘッダーのクリックで昇順/降順ソート
- 行クリックでS02（学習メイン画面）へ遷移
- 概要列は1行に収まらない場合は末尾を「…」で省略

### コンポーネント

| 要素 | 役割 |
|------|------|
| ヘッダー | ロゴ・プロダクト名 |
| 言語フィルタ | DBの言語ラベルを動的列挙。選択した言語で絞り込み |
| 教材テーブル | レッスン番号・タイトル・言語・難易度・概要を一覧表示。言語列でソート可。行クリックで学習開始 |

## S02 学習メイン画面

### レイアウト

```text
┌────────────────────┬──────────────────────────────────────────┐
│ [教材] [LLM]       │                                          │
│                    │   // main.dart                           │
│  教材本文          │   void main() {                          │
│  (Markdown)        │     runApp(MyApp());                     │  ← コードエディタ
│                    │   }                                      │
│  or                │                                          │
│                    │                                          │
│  LLMチャット       │                                          │
│  (タブ切替)        │                                          │
│                    ├──────────────────────────────────────────┤
│                    │ [プレビュー] [コンソール] [ファイル]      │  ← 下部パネル（小）
│                    │  <ビルド結果 / ログ / ファイルツリー>     │
└────────────────────┴──────────────────────────────────────────┘
```

### ペイン構成

#### 左ペイン（固定幅 or リサイズ可）

| タブ | 内容 |
|------|------|
| 教材 | Markdown形式のレッスン本文。ステップ・説明・ヒントを表示 |
| LLM | チャット形式のAI質問UI。現在の教材・コード・エラーをコンテキストとして送信 |

#### 右ペイン

右ペインは縦方向に2分割する。コードエディタを主要領域とし、下部パネルはコンパクトに配置する。

**コードエディタ（上部・主要領域）**

- シンタックスハイライト（Dart対応）
- 行番号表示
- 変更後はビルドボタンで実行

**下部パネル（タブ切替・補助領域）**

| タブ | 内容 |
|------|------|
| プレビュー | Flutter Webビルド結果をiframe等で表示 |
| コンソール | ビルドログ・エラーログをターミナル風UIで表示 |
| ファイル | VSCode風のディレクトリ・ファイルツリー。ファイルをクリックするとエディタに表示 |

### 操作フロー

```text
1. 教材タブで本文を読む
2. 下部パネルの「ファイル」タブで編集対象を選択
3. コードエディタでコードを書く
4. ビルド実行 → プレビューまたはコンソールで結果確認
5. エラー・疑問があればLLMタブで質問
6. コードを修正して再実行
```

### インタラクション詳細

| 操作 | 挙動 |
|------|------|
| タブ切替（教材/LLM） | 左ペインのコンテンツを切り替え。状態は保持 |
| 下部タブ切替（プレビュー/コンソール/ファイル） | 下部パネルのコンテンツを切り替え。状態は保持 |
| ファイルクリック（ファイルタブ内） | エディタにファイル内容をロード。その後プレビューまたはコンソールタブに自動切替（オプション） |
| ビルド実行ボタン | APIを呼びビルド開始。コンソールにログをストリーム表示 |
| プレビュー/コンソール切替 | タブで切り替え。ビルド完了後は自動でプレビューに切替（オプション） |
| LLMに質問 | 送信時に現在の教材ID・コード・コンソールログをペイロードに含める |


## S03 Admin画面

### レイアウト

Admin画面は教材一覧・教材編集の2ビューで構成する。

#### Admin 教材一覧ビュー

```text
┌─────────────────────────────────────────────────────────────┐
│  Admin  /  教材管理                          [+ 教材を追加]  │  ← ヘッダー
├─────────────────────────────────────────────────────────────┤
│  状態: [すべて] [draft] [published]                         │  ← 状態フィルタ
│  言語: [すべて] [Flutter] [React] [Python] ...  [言語 ↕]   │  ← 言語フィルタ・ソート
├─────────────────────────────────────────────────────────────┤
│  2件選択中  [一括操作: 承認して公開 ▼] [実行]  [削除]       │  ← 一括操作バー（選択時のみ表示）
├──┬──────┬──────────────────────┬──────────┬───────┬────────┤
│☐ │ 状態 │ タイトル             │ 言語     │ 更新日 │ 操作  │
├──┼──────┼──────────────────────┼──────────┼───────┼────────┤
│☑ │draft │ Lesson 001: Hello... │ Flutter  │05-25  │[編集][承認]  │
│☑ │draft │ Lesson 002: Widget.. │ Flutter  │05-20  │[編集][承認]  │
│☐ │pub.. │ Lesson 003: 状態管理 │ Flutter  │05-01  │[編集][非公開]│
└──┴──────┴──────────────────────┴──────────┴───────┴────────┘
```

- ヘッダー行のチェックボックスで表示中の全件を選択/解除
- 1件以上選択時に一括操作バーを表示。操作選択肢: 承認して公開 / 非公開にする / 削除する
- 一括操作はすべて確認ダイアログ付き。削除は破壊的操作のため警告を強調表示
- 言語列ヘッダーのクリックでソート（昇順/降順）。言語フィルタはDBに登録済みの言語を動的に列挙
- 個別の承認・非公開ボタンはそれぞれの状態のときのみ表示

#### Admin 教材編集ビュー（追加・編集共通）

```text
┌─────────────────────────────────────────────────────────────┐
│  Admin  /  教材管理  /  Lesson 001                          │
│                              [下書き保存]  [承認して公開する] │
├──────────────┬──────────────────────────────────────────────┤
│ タイトル     │  [___________________________________]        │
│ 言語         │  [Flutter ▼]   ← DBの言語マスタから選択      │
│ 難易度       │  [入門 ▼]                                    │
│ 説明         │  [___________________________________]        │
│ 学習目標     │  [___________________________________]        │
├──────────────┴──────────────────────────────────────────────┤
│  [教材本文] [初期コード] [模範解答]        [プレビュー切替] │  ← 編集タブ
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   テキストエリア（Markdown / コード）                        │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

- 言語はDBの言語マスタをプルダウンで選択
- 教材本文・初期コード・模範解答をタブで切り替えて編集
- プレビュー切替でMarkdownレンダリング／シンタックスハイライト表示に切り替え
- 下書き保存でdraft状態のまま保存

### コンポーネント

| 要素 | 役割 |
|------|------|
| 教材を追加ボタン | 空の教材編集ビューを開く |
| 状態フィルタ | すべて / draft / published で絞り込み |
| 言語フィルタ | DBの言語マスタを動的列挙。選択した言語で絞り込み |
| 言語ソート | 言語列ヘッダークリックで昇順/降順切替 |
| チェックボックス | 行単位の選択。ヘッダーで表示中の全件選択/解除 |
| 一括操作バー | 1件以上選択時に表示。承認して公開 / 非公開にする / 削除する を選択して実行（確認ダイアログ付き。削除は警告強調） |
| 編集ボタン（個別） | 教材編集ビューへ遷移 |
| 承認ボタン（個別） | draft → published。確認ダイアログ付き |
| 非公開ボタン（個別） | published → draft。確認ダイアログ付き |
| 言語プルダウン（編集） | DBの言語マスタから教材の対象言語を選択 |
| メタデータフォーム | タイトル・難易度・説明・学習目標を入力 |
| 編集タブ | 教材本文 / 初期コード / 模範解答を切り替え |
| テキストエリア | Markdownまたはコードを直接編集 |
| プレビュー切替 | 編集中コンテンツをレンダリング表示に切り替え |
| 下書き保存ボタン | draft状態で保存 |
| 承認して公開するボタン | 保存と同時にpublishedへ変更 |

### 操作フロー

```text
【新規追加】
1. [+ 教材を追加] で空の編集ビューを開く
2. メタデータ（タイトル・言語・難易度・説明・学習目標）を入力
3. 教材本文・初期コード・模範解答をタブ切替で編集
4. [プレビュー切替] でレンダリング表示を確認（Markdown表示 / シンタックスハイライト）
5. 問題なければ [承認して公開する] で公開、または [下書き保存] でdraft保存
6. draft保存した場合 → 一覧に戻り [承認] ボタンで後から公開可

【一括ステータス変更】
1. 言語フィルタ・状態フィルタで対象を絞り込む
2. チェックボックスで対象教材を選択（ヘッダーで全選択も可）
3. 一括操作バーから操作を選択（承認して公開 / 非公開にする）
4. 確認ダイアログで確定 → 選択した全教材のステータスを一括変更

【修正・再承認】
1. 一覧から [編集] で教材編集ビューへ遷移
2. 該当箇所を修正
3. [プレビュー切替] で修正後の表示を確認
4. [下書き保存] でdraftに戻す → 確認後 [承認] で再公開
```

### 設計上の前提

- Admin画面へのアクセス制限は初期段階では設けない（個人利用前提）。将来的に公開する場合は別途検討
