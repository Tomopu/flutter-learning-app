## S02 学習メイン画面

### レイアウト

```text
┌────────────────────┬──────────────────────────────────────────┐
│ [教材] [LLM]       │  📁 src/                                  │  ← ファイルツリー
│                    │    └─ lib/                                │
│                    │        └─ main.dart  ← (選択中)           │
│  教材本文          ├──────────────────────────────────────────┤
│  (Markdown)        │                                          │
│                    │   // main.dart                           │
│  or                │   void main() {                          │  ← コードエディタ
│                    │     runApp(MyApp());                     │
│  LLMチャット       │   }                                      │
│  (タブ切替)        │                                          │
│                    ├──────────────────────────────────────────┤
│                    │ [プレビュー] [コンソール]                  │
│                    │                                          │  ← 下部パネル
│                    │  <ビルド結果 / ログ表示>                  │
└────────────────────┴──────────────────────────────────────────┘
```

### ペイン構成

#### 左ペイン（固定幅 or リサイズ可）

| タブ | 内容 |
|------|------|
| 教材 | Markdown形式のレッスン本文。ステップ・説明・ヒントを表示 |
| LLM | チャット形式のAI質問UI。現在の教材・コード・エラーをコンテキストとして送信 |

#### 右ペイン

右ペインは縦方向に3分割する。

**ファイルツリー（上部）**

- VSCode風のディレクトリ・ファイル表示
- MVPでは `lib/main.dart` のみ編集可能
- ファイルをクリックするとエディタに表示

**コードエディタ（中央）**

- シンタックスハイライト（Dart対応）
- 行番号表示
- 変更後はビルドボタンで実行

**下部パネル（タブ切替）**

| タブ | 内容 |
|------|------|
| プレビュー | Flutter Webビルド結果をiframe等で表示 |
| コンソール | ビルドログ・エラーログをターミナル風UIで表示 |

### 操作フロー

```text
1. 教材タブで本文を読む
2. ファイルツリーで編集対象を確認
3. コードエディタでコードを書く
4. ビルド実行 → プレビューまたはコンソールで結果確認
5. エラー・疑問があればLLMタブで質問
6. コードを修正して再実行
```

### インタラクション詳細

| 操作 | 挙動 |
|------|------|
| タブ切替（教材/LLM） | 左ペインのコンテンツを切り替え。状態は保持 |
| ファイルクリック | エディタにファイル内容をロード |
| ビルド実行ボタン | APIを呼びビルド開始。コンソールにログをストリーム表示 |
| プレビュー/コンソール切替 | タブで切り替え。ビルド完了後は自動でプレビューに切替（オプション） |
| LLMに質問 | 送信時に現在の教材ID・コード・コンソールログをペイロードに含める |


## S03 Admin画面

### レイアウト

Admin画面は教材一覧と教材詳細の2ビューで構成する。

#### Admin 教材一覧ビュー

```text
┌─────────────────────────────────────────────────────────────┐
│  Admin  /  教材管理                                          │  ← ヘッダー
├─────────────────────────────────────────────────────────────┤
│  [すべて] [draft] [published]             [教材を追加（将来）] │  ← フィルタタブ
├────────┬──────────────────────┬──────────┬──────────────────┤
│ 状態   │ タイトル             │ 更新日   │ 操作             │
├────────┼──────────────────────┼──────────┼──────────────────┤
│ draft  │ Lesson 001: Hello... │ 2026-05-25 │ [プレビュー]   │
│ draft  │ Lesson 002: Widget.. │ 2026-05-20 │ [プレビュー]   │
│published│ Lesson 003: 状態管理│ 2026-05-01 │ [プレビュー]   │
└────────┴──────────────────────┴──────────┴──────────────────┘
```

#### Admin 教材詳細ビュー（プレビュー）

```text
┌─────────────────────────────────────────────────────────────┐
│  Admin  /  教材管理  /  Lesson 001                          │ 
│                                          [承認して公開する]  │  ← draft時のみ表示
│                                          [非公開にする]      │  ← published時のみ表示
├────────────────────────┬────────────────────────────────────┤
│                        │                                    │
│  教材本文              │  初期コード（initial_code.dart）   │
│  （Markdownプレビュー）│                                    │
│                        ├────────────────────────────────────┤
│                        │                                    │
│                        │  模範解答（solution.dart）         │
│                        │                                    │
└────────────────────────┴────────────────────────────────────┘
```

### コンポーネント

| 要素 | 役割 |
|------|------|
| フィルタタブ | 状態別（すべて/draft/published）の絞り込み |
| 教材テーブル | 教材の状態・タイトル・更新日・操作ボタンを一覧表示 |
| プレビューボタン | 教材詳細ビューへ遷移 |
| 承認して公開するボタン | draft → published に変更。確認ダイアログ付き |
| 非公開にするボタン | published → draft に戻す。確認ダイアログ付き |
| 教材本文プレビュー | Markdownレンダリングで表示（学習画面と同じレンダラ使用） |
| コードプレビュー | 初期コード・模範解答をシンタックスハイライト付きで表示（読み取り専用） |

### 操作フロー

```text
1. 教材一覧を開き、draft状態の教材を確認
2. [プレビュー] で教材詳細ビューに遷移
3. 本文・初期コード・模範解答を確認
4. 問題なければ [承認して公開する] → 確認ダイアログで確定 → published に変更
5. 公開後に誤りを発見した場合は [非公開にする] → draft に戻してファイルを修正 → 再承認
```

### 設計上の前提

- 教材の本文・コードの編集はMarkdownファイルをgit上で直接行う。Admin画面では編集UIは持たない
- Admin画面へのアクセス制限は初期段階では設けない（個人利用前提）。将来的に公開する場合は別途検討
