```text
│  Flutter 実践学習                                            │  ← コース見出し
│                                                             │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐      │
│  │ Lesson 001   │  │ Lesson 002   │  │ Lesson 003   │      │  ← レッスンカード
│  │ Hello World  │  │ Widget基礎   │  │ 状態管理     │      │
│  │ ─────────── │  │ ─────────── │  │ ─────────── │      │
│  │ 難易度: 入門 │  │ 難易度: 入門 │  │ 難易度: 中級 │      │
│  │ [開始する]   │  │ [開始する]   │  │ [開始する]   │      │
│  └──────────────┘  └──────────────┘  └──────────────┘      │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### コンポーネント

| 要素 | 役割 |
|------|------|
| ヘッダー | ロゴ・プロダクト名 |
| コースセクション | コース名と説明文 |
| レッスンカード | タイトル・概要・難易度・開始ボタン |

## S02 学習メイン画面

### レイアウト

```text
┌────────────────────┬──────────────────────────────────────────┐
│ [教材] [LLM]       │  📁 src/                                  │  ← ファイルツリー
│                    │    └─ lib/                                │
│                    │        └─ main.dart  ← (選択中)           │
│  教材本文          ├──────────────────────────────────────────┤
│  (Markdown)        │                                          │
│                    │   // main.dart                           │
│  or                │   void main() {                          │  ← コードエディタ
│                    │     runApp(MyApp());                     │
│  LLMチャット       │   }                                      │
│  (タブ切替)        │                                          │
│                    ├──────────────────────────────────────────┤
│                    │ [プレビュー] [コンソール]                  │
│                    │                                          │  ← 下部パネル
│                    │  <ビルド結果 / ログ表示>                  │
└────────────────────┴──────────────────────────────────────────┘
```

### ペイン構成

#### 左ペイン（固定幅 or リサイズ可）

| タブ | 内容 |
|------|------|
| 教材 | Markdown形式のレッスン本文。ステップ・説明・ヒントを表示 |
| LLM | チャット形式のAI質問UI。現在の教材・コード・エラーをコンテキストとして送信 |

#### 右ペイン

右ペインは縦方向に3分割する。

**ファイルツリー（上部）**

- VSCode風のディレクトリ・ファイル表示
- MVPでは `lib/main.dart` のみ編集可能
- ファイルをクリックするとエディタに表示

**コードエディタ（中央）**

- シンタックスハイライト（Dart対応）
- 行番号表示
- 変更後はビルドボタンで実行

**下部パネル（タブ切替）**

| タブ | 内容 |
|------|------|
| プレビュー | Flutter Webビルド結果をiframe等で表示 |
| コンソール | ビルドログ・エラーログをターミナル風UIで表示 |

### 操作フロー

```text
1. 教材タブで本文を読む
2. ファイルツリーで編集対象を確認
3. コードエディタでコードを書く
4. ビルド実行 → プレビューまたはコンソールで結果確認
5. エラー・疑問があればLLMタブで質問
6. コードを修正して再実行
```

### インタラクション詳細

| 操作 | 挙動 |
|------|------|
| タブ切替（教材/LLM） | 左ペインのコンテンツを切り替え。状態は保持 |
| ファイルクリック | エディタにファイル内容をロード |
| ビルド実行ボタン | APIを呼びビルド開始。コンソールにログをストリーム表示 |
| プレビュー/コンソール切替 | タブで切り替え。ビルド完了後は自動でプレビューに切替（オプション） |
| LLMに質問 | 送信時に現在の教材ID・コード・コンソールログをペイロードに含める |
