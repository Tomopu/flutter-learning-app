# standards

このディレクトリでは、開発・設計・文書化における組織内標準や規定文書を管理します。

標準文書は、個別機能の仕様ではなく、プロジェクト全体で守るルールや判断基準を定義します。

## ドキュメント

- [01_ドキュメント管理規定.md](01_ドキュメント管理規定.md): docs全体の分類、下書きと正式文書の扱い、更新ルール
- [02_コーディング規約.md](02_コーディング規約.md): 実装時の基本的なコード品質ルール
- [03_セキュリティ方針.md](03_セキュリティ方針.md): セキュリティ境界、ビルド環境隔離、LLM生成物の扱い
- [04_技術選定.md](04_技術選定.md): 採用技術、採用理由、見送った技術
- [05_GitHub運用基準.md](05_GitHub運用基準.md): Issue、ブランチ、コミット、Pull Request、レビュー、マージ、リリースの運用基準

## 役割

- `standards` は「どういうルールで作るか」を扱う。
- 要求そのものは [01_requirements/](../01_requirements/) に置く。
- 個別の実現方法は [03_design/](../03_design/) に置く。
- 標準の変更は影響範囲が広いため、関連する設計書も合わせて確認する。
