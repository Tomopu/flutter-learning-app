## 要件の要点

- Flutterコードの実行方式は、テンプレート差し替え方式ではなくサーバービルド方式とする
- MVP第一段階では、ローカルDocker上でフロントエンド、バックエンド、データベース、ビルド環境を動作させる
- MVP第二段階では、クラウド上でビルド用ワークスペースまたはコンテナを生成する
- MVPでは編集対象ファイルを限定せず、プロジェクト全体を編集対象にする
- コードはブラウザ上に保存し、プロジェクト全体のダウンロード・アップロードに対応する
- 破壊的な変更に備え、ファイル単位またはプロジェクト単位で初期状態へリセットできるようにする
- 管理者向け画面で教材の追加・編集、一括公開状態変更、一括削除、言語ラベル管理、LLMによるロードマップ・教材下書き生成、LLM教材修正案生成を扱う
