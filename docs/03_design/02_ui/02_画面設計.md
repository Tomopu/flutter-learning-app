# 画面設計

## S01 教材一覧画面

### レイアウト

```text
┌─────────────────────────────────────────────────────────────┐
│  [ロゴ / プロダクト名]                          [≡ メニュー] │  ← ヘッダー
├─────────────────────────────────────────────────────────────┤
│  学習を始める                                                │  ← ヒーロー
│  レッスンを選んでクリックすると、学習画面が開きます。         │
├─────────────────────────────────────────────────────────────┤
│  [すべて][Flutter][JavaScript]... | [すべて][入門][中級][上級]│  ← 言語・難易度フィルタ
│                                               番号順▼  N件  │  ← ソート・件数
├──────────────────┬──────────────────┬──────────────────────┤
│ #001      ● 入門 │ #002      ● 入門 │ #003      ● 中級    │
│ Hello World      │ Widget基礎       │ 状態管理             │
│ Flutter の基本を…│ ウィジェットの…   │ StatefulWidget で…   │
│ [Flutter]  学習→ │ [Flutter]  学習→ │ [Flutter]  学習→    │
└──────────────────┴──────────────────┴──────────────────────┘
```

- 言語フィルタ・難易度フィルタはそれぞれチップ形式で列挙。両条件を同時に適用可能
- 言語フィルタはDBに登録済みの言語ラベルを動的に列挙
- ソートドロップダウン（番号順・タイトル順・言語順）と件数を右端に配置
- カードクリックでS02（学習メイン画面）へ遷移
- 説明文は2行でクランプし、超過分を「…」で省略

### コンポーネント

| 要素 | 役割 |
|------|------|
| ヘッダー | ロゴ・プロダクト名・メニュー |
| ヒーロー | タイトルと補足説明文。フィルタ・グリッドの前に表示 |
| 言語フィルタ | DBの言語ラベルを動的列挙。選択した言語で絞り込み |
| 難易度フィルタ | 入門・中級・上級の3択チップ。選択した難易度で絞り込み |
| ソートドロップダウン | 番号順・タイトル順・言語順から選択 |
| 件数表示 | フィルタ後の表示件数をリアルタイムで表示 |
| レッスンカード | レッスン番号・難易度バッジ・タイトル・説明・言語バッジ・「学習する」CTAを表示。クリックで学習開始 |

## S02 学習メイン画面

### レイアウト

```text
┌──────────────────────────────────────────────────────────────────────────┐
│ [← 戻る] | #001  Hello World  [Flutter] ● 入門  [✓ ビルド成功 · 9.2s]  [リセット][▶ ビルド] │  ← トップツールバー
├────────────────────┬─────────────────────────────────────────────────────┤
│ [教材] [解答] [LLM]│ [📄 main.dart ●] [📄 pubspec.yaml]  Dart · LF · UTF-8│  ← エディタファイルタブ
│                    │   // main.dart                                      │
│  教材本文          │   void main() {                                     │
│  (Markdown)        │     runApp(MyApp());                                │  ← コードエディタ
│                    │   }                                                 │
│  or                │                                                     │
│  解答パネル        │                                                     │
│                    │                                                     │
│  or                │                                                     │
│  LLMチャット       │                                                     │
│                    ├─────────────────────────────────────────────────────┤
│                    │ [プレビュー] [コンソール] [ファイル]                 │  ← 下部パネル（タブ切替）
│                    │  <ビルド結果 / ログ / ファイルツリー>                │
└────────────────────┴─────────────────────────────────────────────────────┘
```

### トップツールバー

S02全体の最上部に固定配置する。

| 要素 | 内容 |
|------|------|
| 戻るボタン | S01（教材一覧）へ戻る |
| レッスン番号 | `#001` 形式のモノスペース表示 |
| レッスンタイトル | 教材名 |
| 言語・難易度バッジ | レッスンのメタ情報 |
| ビルドステータス | ビルド中・成功・失敗をドット＋テキスト＋経過秒数で表示 |
| リセットボタン | 現在のファイル（lib/main.dart）を初期コードに戻す。確認なし |
| ビルドボタン | Flutter Webビルドを実行。ビルド中はスピナーに変化しdisabled |

### ペイン構成

#### 左ペイン（リサイズ可）

| タブ | 内容 |
|------|------|
| 教材 | Markdown形式のレッスン本文。ステップ・説明・ヒントを表示 |
| 解答 | 模範解答パネル。初回はゲート画面を表示し、確認後にコードブロックを表示 |
| LLM | チャット形式のAI質問UI。現在の教材・コード・コンソールログをコンテキストとして送信 |

**解答タブの動作**

初回表示時はゲート画面を表示し、学習者が不用意に解答を見てしまわないようにする。「模範解答を表示する」ボタンをクリックすると解答を表示する。表示後は以下のボタンが使用可能になる。

- **コピー**: 解答コードをクリップボードにコピー
- **エディタに反映**: 解答コードを `lib/main.dart` に上書き適用

#### 右ペイン

右ペインは縦方向に2分割する。コードエディタを主要領域とし、下部パネルはコンパクトに配置する。

**コードエディタ（上部・主要領域）**

Monaco Editorを使用する。ファイルタブ付きで複数ファイルを同時に開ける。

| 要素 | 内容 |
|------|------|
| ファイルタブストリップ | 開いているファイルをタブで表示。アクティブなタブをクリックで切替、×ボタンで閉じる |
| 未保存インジケータ | 編集済みファイルのタブにオレンジのドットを表示 |
| メタ情報 | タブストリップ右端に言語・改行コード・文字コードを表示（例: `Dart · LF · UTF-8`） |
| エディタ本体 | シンタックスハイライト（Dart対応）、行番号表示、タブサイズ2 |

**下部パネル（タブ切替・補助領域）**

| タブ | 内容 |
|------|------|
| プレビュー | Flutter Webビルド結果をデバイスフレーム内に表示。ビルド中はスピナー、エラー時はエラーメッセージ |
| コンソール | ビルドログ・エラーログをターミナル風UIで表示（タイムスタンプ付き、色分け） |
| ファイル | VSCode風のディレクトリ・ファイルツリー。クリックでエディタに表示 |

### 操作フロー

```text
1. 教材タブで本文を読む
2. 下部パネルの「ファイル」タブで編集対象を選択（エディタにファイルが追加される）
3. コードエディタでコードを書く
4. ビルドボタンで実行 → コンソールに経過ログ → 完了でプレビューに自動切替
5. エラー・疑問があればLLMタブで質問
6. コードを修正して再実行
7. 自力で進めた後、解答タブでゲートを通過して解答例を確認
8. 必要に応じて「エディタに反映」ボタンで解答コードを適用
```

### インタラクション詳細

| 操作 | 挙動 |
|------|------|
| タブ切替（教材/解答/LLM） | 左ペインのコンテンツを切り替え。各タブの状態は保持 |
| 解答タブの初回表示 | ゲート画面を表示。「模範解答を表示する」をクリックで解答を表示 |
| 「エディタに反映」ボタン | 解答コードを `lib/main.dart` に上書き。activeファイルも `lib/main.dart` に切り替え |
| ファイルタブクリック | エディタの表示ファイルを切り替え。未開のファイルはファイルツリーから開く |
| ファイルタブの×ボタン | タブを閉じる。最後の1タブは閉じられない |
| ビルドボタン | APIを呼びビルド開始。コンソールに経過をストリーム表示。完了後にプレビューへ自動切替 |
| リセットボタン | `lib/main.dart` を初期コードに戻す（確認ダイアログなし） |
| ファイルクリック（ファイルタブ内） | エディタにファイルをタブとして追加し、アクティブにする |
| ビルドステータス表示 | ビルド中: スピナー＋「ビルド中…」 / 成功: 緑ドット＋「ビルド成功」＋秒数 / 失敗: 赤ドット＋「ビルド失敗」＋秒数 |
| LLMに質問 | 送信時に現在の教材番号・アクティブファイル名・コンソールログをコンテキストに含める |


## S03 Admin画面

### レイアウト

Admin画面は教材一覧・教材編集の2ビューで構成する。

#### Admin 教材一覧ビュー

```text
┌─────────────────────────────────────────────────────────────┐
│  Admin  /  教材管理                          [+ 教材を追加]  │  ← ヘッダー
├─────────────────────────────────────────────────────────────┤
│  状態: [すべて][下書き][公開中]                               │  ← 状態フィルタ
│  言語: [すべて][Flutter][React][Python] ...                  │  ← 言語フィルタ
│                                                      N 件   │
├─────────────────────────────────────────────────────────────┤
│  2件選択中  一括操作: [承認して公開 ▼] [実行]  [選択解除]    │  ← 一括操作バー（選択時のみ）
├──┬──────┬──────────────────────┬──────────┬──────┬────────┬────────┤
│☐ │ 状態 │ タイトル ↕           │ 言語 ↕   │ 難易度│ 更新日 ↕│ 操作  │
├──┼──────┼──────────────────────┼──────────┼──────┼────────┼────────┤
│☑ │下書き│ #001 Hello World...  │ Flutter  │ 入門  │ 05-25  │[編集][承認]  │
│☑ │下書き│ #002 Widget基礎..    │ Flutter  │ 入門  │ 05-20  │[編集][承認]  │
│☐ │公開中│ #003 状態管理         │ Flutter  │ 中級  │ 05-01  │[編集][非公開]│
└──┴──────┴──────────────────────┴──────────┴──────┴────────┴────────┘
```

- 状態フィルタ: すべて / 下書き / 公開中（チップ形式）
- 言語フィルタ: DBに登録済みの言語を動的列挙（チップ形式）
- タイトル・言語・更新日列ヘッダーのクリックで昇順/降順ソート
- 難易度列は表示のみ（ソートなし）
- ヘッダー行のチェックボックスで表示中の全件を選択/解除
- 1件以上選択時に一括操作バーを表示。操作選択肢: 承認して公開 / 非公開にする / 削除する
- 一括操作はすべて確認ダイアログ付き。削除は破壊的操作のため警告を強調表示
- 個別の承認・非公開ボタンはそれぞれの状態のときのみ表示

#### Admin 教材編集ビュー（追加・編集共通）

```text
┌─────────────────────────────────────────────────────────────┐
│  Admin  /  教材管理  /  Lesson 001           [一覧へ戻る]   │
│                              [下書き保存]  [承認して公開する] │
├──────────────┬──────────────────────────────────────────────┤
│ タイトル     │  [___________________________________]        │
│ 言語         │  [Flutter ▼]   難易度: [入門 ▼]            │
│ 現在の状態   │  ● 下書き                                   │
│ 説明（概要） │  [___________________________________]        │
│ 学習目標     │  [___________________________________]        │
├──────────────┴──────────────────────────────────────────────┤
│  [教材本文] [初期コード] [模範解答]            編集/プレビュー│  ← 編集タブ
├─────────────────────────────────────────────────────────────┤
│  教材本文タブ: Markdownテキストエリア（プレビュートグル切替） │
│  初期コード/模範解答タブ: ファイルリスト＋Monacoエディタ     │
│    ┌──────────────┐  ┌──────────────────────────────────┐  │
│    │ファイル      │  │ lib/main.dart                   │  │
│    │> main.dart  │  │                                  │  │
│    │  pubspec.yml│  │   （Monaco Editor）               │  │
│    │[+ ファイル] │  │                                  │  │
│    └──────────────┘  └──────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
```

- 言語・難易度はセレクトボックスで選択
- 現在の状態（下書き/公開中）はバッジで表示のみ
- 教材本文タブ: テキストエリアで直接編集。右端のトグルで「編集」/「プレビュー」を切替
- 初期コード・模範解答タブ: 複数ファイルを管理可能
  - 左列: ファイル一覧（クリックで切替、×で削除、「＋ ファイルを追加」で追加）
  - 右エリア: パス入力＋Monaco Editor
  - ファイルのパス（例: `lib/main.dart`）は直接編集可能
- 下書き保存でdraft状態のまま保存

### コンポーネント

| 要素 | 役割 |
|------|------|
| 教材を追加ボタン | 空の教材編集ビューを開く |
| 状態フィルタ | すべて / 下書き / 公開中 で絞り込み（チップ形式） |
| 言語フィルタ | DBの言語マスタを動的列挙。選択した言語で絞り込み（チップ形式） |
| ソート | タイトル・言語・更新日列ヘッダークリックで昇順/降順切替 |
| チェックボックス | 行単位の選択。ヘッダーで表示中の全件選択/解除 |
| 一括操作バー | 1件以上選択時に表示。承認して公開 / 非公開にする / 削除する を選択して実行（確認ダイアログ付き。削除は警告強調） |
| 選択解除ボタン | 一括操作バー右端に配置。選択をすべて解除 |
| 編集ボタン（個別） | 教材編集ビューへ遷移 |
| 承認ボタン（個別） | 下書き → 公開中。確認ダイアログ付き |
| 非公開ボタン（個別） | 公開中 → 下書き。確認ダイアログ付き |
| メタデータフォーム | タイトル・言語・難易度・説明・学習目標を入力。現在の状態をバッジ表示 |
| 言語セレクト（編集） | DBの言語マスタから教材の対象言語を選択 |
| 難易度セレクト（編集） | 入門・中級・上級から選択 |
| 編集タブ | 教材本文 / 初期コード / 模範解答を切り替え |
| 教材本文エリア | Markdownテキストエリア。右端トグルでプレビューに切替 |
| 複数ファイルエディタ | 初期コード・模範解答用。ファイルリスト＋Monaco Editor。ファイルの追加・削除・パス変更可 |
| 下書き保存ボタン | 下書き状態で保存 |
| 承認して公開するボタン | 確認ダイアログ後、保存と同時に公開中へ変更 |

### 操作フロー

```text
【新規追加】
1. [+ 教材を追加] で空の編集ビューを開く
2. メタデータ（タイトル・言語・難易度・説明・学習目標）を入力
3. 教材本文タブでMarkdownを編集。プレビュートグルで表示を確認
4. 初期コードタブでファイルを追加・編集（lib/main.dart から開始）
5. 模範解答タブで解答コードを編集
6. 問題なければ [承認して公開する] で公開、または [下書き保存] でdraft保存
7. draft保存した場合 → 一覧に戻り [承認] ボタンで後から公開可

【一括ステータス変更】
1. 言語フィルタ・状態フィルタで対象を絞り込む
2. チェックボックスで対象教材を選択（ヘッダーで全選択も可）
3. 一括操作バーから操作を選択（承認して公開 / 非公開にする）
4. 確認ダイアログで確定 → 選択した全教材のステータスを一括変更

【修正・再承認】
1. 一覧から [編集] で教材編集ビューへ遷移
2. 該当箇所を修正
3. プレビュートグルで修正後の表示を確認
4. [下書き保存] でdraftに戻す → 確認後 [承認] で再公開
```

### 設計上の前提

- Admin画面へのアクセス制限は初期段階では設けない（個人利用前提）。将来的に公開する場合は別途検討
