## 各画面の概要

### S01 教材一覧画面

学習を始めるトップページ。ヒーローセクションとカードグリッドでレッスン一覧を表示する。

- ヒーローセクション（タイトル・説明文）
- 言語フィルタ＋難易度フィルタ（チップ形式、複数条件を同時適用）
- ソートドロップダウン（番号順・タイトル順・言語順）＋件数表示
- レッスンカード: レッスン番号・難易度バッジ・タイトル・説明・言語バッジ・「学習する」CTA
- カードクリックでS02へ遷移

### S02 学習メイン画面

本プロダクトのコア画面。以下の機能パネルを1画面に統合する。

- **トップツールバー**: 戻るボタン・レッスン情報（番号・タイトル・言語・難易度）・ビルドステータス・リセット・ビルドボタン
- **教材パネル（左ペイン・タブ①）**: Markdown形式のレッスン本文を表示
- **解答パネル（左ペイン・タブ②）**: 模範解答をゲート確認後にコードブロックで表示。コピー・エディタへの反映ボタン付き
- **LLMチャットパネル（左ペイン・タブ③）**: 教材・コード・エラーをコンテキストにしたAI質問
- **コードエディタ（右ペイン・上部・主要領域）**: ファイルタブ付きDart/Flutterコード編集（Monaco Editor）
- **プレビュー / コンソール / ファイルツリー（右ペイン・下部・タブ切替）**: ビルド結果・ログ・ファイル選択

### S03 Admin画面

教材のライフサイクル全体を管理する管理者向け画面。学習者向けの画面とは独立して存在する。

- 下書き / 公開中 状態の教材一覧を表示（フィルタ・ソート対応）
- 教材の新規追加・編集（教材本文・初期コード・模範解答をタブ切替）
  - 教材本文: Markdownテキストエリア＋編集/プレビュー切替
  - 初期コード・模範解答: 複数ファイル対応のMonacoエディタ（ファイル追加・削除・パス変更可）
- 承認操作（下書き → 公開中）：個別ボタン / 一括操作の両方に対応
- 公開済み教材の確認・非公開化
