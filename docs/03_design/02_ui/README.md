# ui

このディレクトリでは、画面構成、画面設計、UI方針を管理します。

UI設計は、要求仕様をユーザーが操作できる画面とインタラクションへ落とし込むための設計書です。

## ドキュメント

- [01_画面一覧.md](01_画面一覧.md): 画面構成、画面遷移、各画面の概要
- [02_画面設計.md](02_画面設計.md): 各画面のレイアウト、コンポーネント、操作フロー
- [03_UI方針.md](03_UI方針.md): カラー、タイポグラフィ、レイアウト、コンポーネント方針
