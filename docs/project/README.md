## 現在の開発方針

MVPは2段階で実装します。

### 第一段階: ローカルDockerアプリケーション方式

フロントエンド、バックエンド、データベース、ビルド実行環境をローカルDocker上で起動し、ユーザーのローカル環境内でサーバービルドを実行します。

### 第二段階: クラウドサーバービルド方式

GCP、AWSなどのクラウド上にアプリケーションをデプロイし、ビルド要求ごとに一時的なワークスペースまたはコンテナを生成します。
