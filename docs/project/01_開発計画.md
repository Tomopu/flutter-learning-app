- Docker

## LLM連携

以下の情報をまとめてLLMに渡し、教材文脈に沿った回答を生成する。

- 教材本文
- 現在のコード
- 実行ログ
- エラーログ
- ユーザーの質問

## 開発体制

開発人数は2人を想定する。

開発には以下のAI開発支援ツールを活用する。

- Claude Code
- Codex
- Antigravity

AIには、ドキュメント作成、Issue分割、実装補助、コードレビュー補助、教材生成補助を担わせる。

ただし、以下については人間が責任を持つ。

- プロダクト方針
- MVPスコープ
- アーキテクチャ判断
- 教材内容の正確性
- 公開判断
- セキュリティ判断

## 開発の進め方

1. プロダクト概要を整理する
2. MVPスコープを定義する
3. 1つ目のFlutter教材を作成する
4. コードエディタを表示する
5. Flutterテンプレートプロジェクトを用意する
6. ユーザーコードをテンプレートに反映する
7. Flutter Webとして実行またはビルドする
8. 実行結果をプレビュー表示する
9. ビルドログ・エラーログを表示する
10. LLM質問機能を追加する
11. GitHub IssueとProjectでタスク管理する

## GitHub Project管理

GitHub Projectでは、以下のステータスを使用する。

```text
Backlog
Ready
In Progress
Review
Done
```

IssueはEpic単位で整理する。

```text
Epic: Product Definition
Epic: Technical Research
Epic: UI Prototype
Epic: Build Execution
Epic: LLM Assistant
Epic: Content Management
Epic: Admin Review Flow
```

## 備考

本プロダクトは、初期段階では個人利用を目的とした開発プロジェクトとする。

外部公開、商用展開、複数ユーザー利用を行う場合は、セキュリティ、利用規約、教材著作権、AI生成コンテンツの品質管理、実行環境の隔離、運用コストを改めて検討する。
